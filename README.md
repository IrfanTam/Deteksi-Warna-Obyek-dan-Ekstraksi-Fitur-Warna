# Deteksi Warna Obyek dan Ekstraksi Fitur Warna 🎨🧠

Repositori ini berisi implementasi praktikum pengolahan citra digital menggunakan Python dan OpenCV, dengan fokus pada:
- Deteksi warna dominan dalam citra.
- Visualisasi histogram RGB.
- Peningkatan kualitas visual melalui histogram equalization (grayscale & berwarna).

Repositori ini mendukung proses pembelajaran pada mata kuliah **Computer Vision** atau **Pengolahan Citra Digital**.
